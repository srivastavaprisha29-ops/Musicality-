## WHAT IF LINKEDIN ACTUALLY FELT LIKE MUSIC?
 
Musicality is a professional discovery network built around sound instead of résumés.
 
<table>
<tr>
<td width="50%" valign="top">
**Musicians** discover musicians
**Producers** discover singers
**Bands** find members
**Composers** find projects
 
</td>
<td width="50%" valign="top">
**Studios** find talent
**Labels** discover creators
**Companies** discover creators
**Creators** discover companies
 
</td>
</tr>
</table>
No résumés. No cover letters. Just profiles built the way an artist actually thinks — genre, sound, taste, and what you're looking to make next.


## DATABASE DESIGN
 
```mermaid
erDiagram
    USERS ||--|| PROFILES : has
    USERS ||--o{ PROFILE_QUESTIONS : answers
    PROFILES ||--o{ OPPORTUNITIES : posts
    USERS ||--o{ MESSAGES : sends
    USERS ||--o{ CONNECTIONS : forms
 
    USERS {
        uuid id
        string name
        string username
        string profile_type
        string bio
        string location
        string avatar
        string availability
    }
    PROFILES {
        uuid user_id
        string role
        string genre
        string skills
        string experience
        string looking_for
    }
    PROFILE_QUESTIONS {
        uuid id
        uuid user_id
        string question
        string answer
    }
    OPPORTUNITIES {
        uuid id
        uuid profile_id
        string title
        string description
        string requirements
    }
    MESSAGES {
        uuid id
        uuid sender_id
        uuid receiver_id
        string reply_context
        string message
        datetime created_at
    }
    CONNECTIONS {
        uuid user_a
        uuid user_b
        string status
    }
```
